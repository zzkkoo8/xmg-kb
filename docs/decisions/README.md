# 架构决策记录（ADR）

本目录保存影响长期架构、接口、数据边界或组件替换的重要决策。

新增 ADR 使用：

```text
ADR-XXXX-short-title.md
```

每份 ADR 至少包含：

- Status；
- Context；
- Decision；
- Alternatives；
- Consequences；
- Validation；
- Rollback。
